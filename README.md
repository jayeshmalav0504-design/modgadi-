# ModGadi (Apni Gadi Ko Sahi Tarike Se Modify Karein) 🚗🇮🇳

India's transparent Car Modification Roadmap, Area-Wise Cost Estimator, State RTO Legal Checker, and Verified Workshop Finder.

## Features
- **Cinematic Video Intro & Studio Backdrop**: Daylight automotive theme featuring full-screen starting intro and live Red Bull F1 livery & custom livery video backgrounds.
- **8 RTO Zones Covered**: Jaipur (RJ-14), Delhi NCR (DL), Bengaluru (KA-01), Mumbai (MH-01/02), Chandigarh (CH-01), Pune (MH-12), Hyderabad (TS-09), and Kochi (KL-07).
- **5 Vehicle Segments (A to E)**: Sizing & labor multipliers covering hatchbacks, compact SUVs, sedans/EVs, mid-size SUVs, and full-size 4x4s (Maruti, Hyundai, Tata, Mahindra, Toyota).
- **16 Categorized Modifications**: Self-healing TPU PPF, vinyl wraps, alloys, AT tyres, aero splitters, roof racks, ARAI projector LEDs, heat films, nappa interiors, audio damping, and Stage 1 remaps with transparent Parts + Studio Labor pricing.
- **RTO Compliance Badges**: 🟢 100% Legal Nationwide, 🟡 RC Endorsement Required (MVA Sec. 52 / Parivahan Form 24), and 🔴 Restricted / Challan risk.
- **Interactive Google Maps Integration**: Uses the modern Google Maps JS API loader (`@googlemaps/js-api-loader` style) to pinpoint verified workshops and detailing studios in each city.
- **ElevenLabs AI Voiceover (`https://api.elevenlabs.io/v1`)**: Integrated AI speech narration with dynamic waveform visualizer and speech synthesis fallback.
- **One-Tap WhatsApp Studio Export**: Generates pre-formatted itemized builds directly to detailing workshops.

## Running the Project
Simply open `index.html` in any modern web browser or host on GitHub Pages.
